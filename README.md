# Abrigo Saúde PME

Página + fluxo de atendimento para venda de planos de saúde PME.

A cotação começa com uma conversa: a assistente virtual Bia qualifica o lead (cidade, vidas, idades, plano atual), mostra uma primeira simulação, recomenda conforme a prioridade do cliente e transfere para o corretor na hora certa, com a mensagem pronta para continuar no WhatsApp.

- **Visão do corretor:** dados capturados, lead score, intenção, status e regras de transferência.
- **WhatsApp:** o botão "Abrir no WhatsApp" abre a conversa com a mensagem da simulação já preenchida (link `wa.me`).
- **Tecnologia:** um único arquivo HTML, com CSS e JavaScript puros, sem dependências.

Planos e valores são demonstrativos e não representam cotação de operadora.
